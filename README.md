# «Хвоя» — демо-сайт каркасных домов под ключ

Демо-проект для портфолио. Компания вымышленная: телефон, «Обсудить дом» и другие кнопки связи показывают плашку «Это пробный сайт» со ссылкой на Telegram @isthisthedaggr. Цены ориентировочные.

Идея: дом, который можно разобрать на части. На первом экране — точки на фото с ценой каждой части, дальше — конфигуратор со сметой по статьям и 3D-моделью, каталог из восьми проектов и сборка дома по своему чертежу.

## Страницы

- `index.html` — главная: фото с точками-ценами, основатель, договор в пяти строках, ползунок «до и после» по этапам стройки, быстрый расчёт, проекты, люди, отзыв
- `konfigurator.html` — конфигуратор: 9 групп параметров, 3D-модель, смета-документ по статьям, печать и ссылка на смету
- `po-chertezhu.html` — дом по своему чертежу: обвести план, задать масштаб, окна и вход → 3D по контуру и смета
- `proekty.html` — каталог с фильтрами; `proekt.html?id=…` — страница проекта: планировка, состав, 3D, смета, платежи
- `chto-vhodit.html` — что входит в тёплый контур, под чистовую и под ключ; чего нет в цене
- `etapy.html` — график стройки по неделям и платежи после этапов
- `garantii.html` — сроки гарантии, гарантийный случай, образец договора
- `404.html` — «Здесь пока только сосны» (все пути от корня сайта)

## Устройство

Статический сайт без сборки: HTML, CSS, JavaScript.

- `js/data.js` — проекты, комнаты, тексты
- `js/price.js` — единая модель цены: смета, сроки, платежи. Цены проектов на всех страницах считаются отсюда
- `js/home.js`, `js/konf.js`, `js/catalog.js`, `js/info.js` — страницы
- `js/house3d.js` — 3D-модель в конфигураторе и на страницах проектов (three.js r160 в `js/vendor/three/`)
- `js/plan-editor.js`, `js/plan-page.js`, `js/plan3d.js` — дом по чертежу
- `js/site.js` — плашка пробного сайта и меню на телефоне

3D: модели `img/3d/*.glb` и картинки-постеры `img/3d/*.jpg` сделаны в Blender. На телефоне 3D грузится только по кнопке, до этого показан постер. Текстуры (ambientCG, CC0) — в `img/tex/`.

Шрифты лежат в `fonts/` (Science Gothic, Golos Text, Cormorant Garamond — Google Fonts, SIL OFL), подключены в `css/fonts.css`. Фото: Unsplash, лежат в `img/ph/`, список в `photos.txt`.
